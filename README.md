Project Overview

NovaTech Solutions is a small IT services business that provides technology-related solutions to individuals and small businesses. This project involved designing and developing a professional, responsive website that gives potential customers information about the business, its services, and how to make contact.

The website consists of five main pages: Home, About Us, Services, Enquiry, and Contact. It uses consistent branding, navigation, images, and a user-friendly interface to make information easy to access.

The website was developed using HTML, CSS, and JavaScript in Visual Studio Code. JavaScript was used to introduce interactive functionality, including service searching, image enlargement, and form validation. The contact form also uses FormSubmit to submit customer messages through email.

The website incorporates responsive design principles, search engine optimisation (SEO) elements, an embedded Google Map, and supporting website files such as "robots.txt" and "sitemap.xml".

The project aims to provide NovaTech Solutions with an accessible online presence where customers can learn about available IT services, submit enquiries, and contact the business.






Key Features and Functionality

- Navigation Bar: Provides links to the Home, About Us, Services, Enquiry, and Contact pages.
- Home Page: Introduces NovaTech Solutions and provides an overview of the business.
- About Us Page: Explains the business, its purpose, mission, vision, and target customers.
- Services Page: Displays Website Development, IT Support, and Computer Repairs with descriptions and images.
- Service Search: Allows visitors to search and filter the available services using JavaScript.
- Interactive Image Gallery: Allows visitors to enlarge service images using a lightbox feature.
- Enquiry Form: Collects customer details and service enquiries, with JavaScript validation.
- Contact Form: Collects customer contact details, message type, and message. JavaScript validates the information, and FormSubmit AJAX is used to submit messages by email.
- Contact Information: Displays the business contact details and an embedded Google Map.
- Responsive Design: Uses CSS media queries to improve the website layout on desktop, tablet, and mobile devices.
- Search Engine Optimisation (SEO): Includes page titles, meta descriptions, heading structure, image alternative text, internal links, "robots.txt", and "sitemap.xml".
- Consistent Styling: Maintains consistent branding, colours, typography, spacing, and page layouts throughout the website.

Project Development Details

Part 1: Planning and Initial Website Development

Part 1 focused on planning the NovaTech Solutions website, identifying the business concept, target audience, website objectives, and required pages.

The initial project structure was created, including the HTML pages, CSS stylesheet, and image folders. Basic page content and navigation links were also developed.

Setup & Local Execution Instructions

Requirements

- Visual Studio Code.
- A modern web browser such as Google Chrome.
- Live Server extension for Visual Studio Code (recommended).
- An internet connection for external services such as Google Maps and FormSubmit.

Installation and Execution

1. Clone the project repository from GitHub:
   
   "git clone <repository-url>"

2. Open the downloaded NovaTech Solutions project folder in Visual Studio Code.

3. Ensure that the project files and folders retain their original structure, including the HTML pages, CSS folder, JavaScript folder, and image folders.

4. Install the Live Server extension in Visual Studio Code if it is not already installed.

5. Open "index.html", right-click inside the editor, and select Open with Live Server.

6. Use the navigation bar to access the Home, About Us, Services, Enquiry, and Contact pages.

7. Test the website's interactive features, including service searching, image enlargement, and form validation.

Note: The contact form requires an internet connection and an active FormSubmit configuration to submit messages successfully.
