Project Overview
NovaTech Solutions is a small IT services business that provides technology-related solutions to individuals and small businesses. The project involved designing and developing a professional website that gives potential customers clear information about the business, its services, and how to make contact.
The website provides a structured online presence for NovaTech Solutions through separate pages for the Home, About Us, Services, Enquiry, and Contact sections. The design uses consistent branding, navigation, images, and a simple user interface to make the information easy to find. The project was developed using HTML and CSS in Visual Studio Code, with supporting web services such as Google Forms and an embedded map used where required.
The website addresses the need for a small IT business to have an accessible online platform where customers can learn about available services, submit enquiries, and find the business location.
Website Goals and Objectives
•	Primary Goal: Create a professional, informative, and user-friendly online presence for NovaTech Solutions.
•	Objective 1: Present the business and its IT services clearly so that visitors can understand what NovaTech Solutions offers.
•	Objective 2: Provide straightforward navigation between the Home, About Us, Services, Enquiry, and Contact pages.
•	Objective 3: Make it easy for potential customers to communicate with the business through the enquiry and contact features.
•	Objective 4: Use responsive web design principles so the website can be viewed on desktop computers, tablets, and mobile devices.
•	Objective 5: Maintain consistent visual branding, page structure, images, and typography throughout the website.
Key Features and Functionality
•	Navigation Bar: Provides links to the Home, About Us, Services, Enquiry, and Contact pages.
•	Home Page: Introduces NovaTech Solutions and gives visitors an overview of the business and its purpose.
•	About Us Page: Provides information about the business and its role in delivering IT solutions.
•	Services Page: Displays the main services offered, including Website Development, IT Support, and Computer Repairs, together with relevant descriptions and images.
•	Enquiry Form: Uses an embedded Google Form to allow potential customers to submit their details and enquiries.
•	Contact Page: Provides contact information and an embedded map to assist customers in locating the business.
•	Visual Content: Uses the NovaTech Solutions branding, service images, and supporting visual elements to improve presentation and communicate the services.
•	Responsive Layout: Uses responsive HTML/CSS design principles to improve usability across different screen sizes, including mobile devices.
•	Consistent Styling: Maintains a consistent colour scheme, typography, spacing, and navigation structure across the website.
